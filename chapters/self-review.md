# 用這套方法審它自己：四份可以直接複製的審查提示詞

> 本章是第八部的配套。第八部講的是**為什麼**這樣分工，這一章給的是**可以直接貼**的四份提示詞。
> 這四份不是設計出來的，是七輪審查一路被漏網的問題逼出來的——每一條規則後面都有一次教訓。
> 所有數字與案例都來自 FinFlow 課程本身的審查過程，可以在專案的開發紀錄裡查到。

---

## 開始之前：三條紀律

**一、一個視窗只演一個角色，互不知情。** 同一輪的不同角色一定要各自開新對話。讓它們看到彼此的報告，第二個角色會順著第一個走，你就從兩份報告退化成一份。

**二、換材料可以續用，換「用什麼眼睛看」要開新視窗。** 同一個角色審不同章節，續用同一個對話串沒問題——實測沒有污染，因為提示詞自己帶齊了背景。但從「審一個章節」換成「通讀全書」，一定要開新視窗，否則它會被前面的章節結論綁住，繼續挑細節，看不見跨章節的問題。

**三、被工具擋住就換入口。** 如果 AI 說讀不到你的網址，先換一個介面試試——同一家的模型裝在不同的殼裡，能做的事不一樣。不要因為一個介面做不到，就以為這個 AI 做不到。真的都不行，就把內容直接貼進對話框。

---

## 為什麼是這三個角色

| 角色 | 它問的那句話 | 它專門抓的 |
| :--- | :--- | :--- |
| 讀者 | 「我看不懂」 | 術語、跳步、前面沒教就用了的東西 |
| 編輯 | 「這兩處對不起來」 | 前後矛盾、承諾沒兌現、口徑不一 |
| 懷疑論者 | 「這是真的嗎」 | 沒有依據的數字、把個案寫成通則 |

第四份是**通讀**——它不是第四個角色，是同樣三雙眼睛換一個尺度：只看跨章節，不看單頁。

實測過一件事：兩個不同的 AI 演同一個角色，重疊率四成五；同一個 AI 演兩個不同角色，重疊率只有一到兩成。**角色決定你會找到什麼，模型幾乎不影響。** 所以要幾個角色就開幾個視窗，不要同一個角色找兩家做。

## 提示詞一・讀者

把 `<你的材料>` 換成你的檔案網址或直接貼上內容，把 `<背景>` 換成三五句話說明這是什麼、給誰看的。

```
你是一位讀者審查員。請只用「第一次讀到這份材料的新手」的身分閱讀，
不要用作者或編輯的身分。

【你要審的材料】
<你的材料>

【背景】
<背景：這是什麼、給誰看、讀者讀到這裡之前已經知道什麼>

【請你分成這幾類回報】
A 類・硬矛盾：同一份材料裡兩處說法互相打架。
B 類・讀不懂：術語、簡稱、只有作者知道的內部說法。
C 類・承諾沒兌現：前面說「後面會講」，結果沒有，或講的跟預告的不一樣。
D 類・宣稱過頭：宣稱讀者「已經完成／已經學會」某件事，但材料撐不起這個宣稱。
E 類・排版雜訊：多餘符號、粗體沒生效、標點錯、表格欄位對不上、數字前後不一致。

【硬性規則】
1. 每一條回報都必須附上原文引述。引述必須是原文，一字不改，
   不可以改寫、濃縮或憑印象寫。你引不出原文的，就不要寫。
2. 涉及數字的判斷，請把算式寫出來，不要只給結論。
3. 你的報告會交給另一位審查者逐條覆驗，任何捏造或記錯都會被抓出來。
   不確定的請標「不確定」，不要猜。
4. 用繁體中文。

【回報格式】
每一條：類別 / 位置 / 原文引述 / 問題是什麼 / 你建議怎麼改（一句話）。
最後給一個各類別的條數統計。
```

**E 類是後來補上去的。** 前面幾輪四個角色全部都在讀內容，沒有一個在檢查產物，結果一個多餘的符號在兩份報告六十幾條裡沒有人看到。把「排版雜訊」寫成明確類別之後，這一類就再也沒漏過——**檢查類別一旦講明，AI 就做得到；缺的從來不是能力，是有沒有叫它看那個維度。**

## 提示詞二・編輯

```
你是一位資深編輯。請用「這份東西要交出去、我要為它的一致性負責」的標準審查。

【你要審的材料】
<你的材料>

【背景】
<背景>

【請你分成這幾類回報】
A 類・硬矛盾：同一份材料裡兩處說法互相打架，或跟參照材料打架。
C 類・承諾沒兌現：前面開的支票，後面有沒有真的兌現、兌現得對不對。
D 類・宣稱過頭：對成果或效果的宣稱，材料本身撐得住嗎？撐不住的請具體指出。
E 類・排版雜訊與口徑不一：粗體、標點、表格欄位，以及全篇統一的數字有沒有寫錯。
F 類・索引正確性：材料裡每一處「見第 X 頁／第 X 節」，
     請逐一確認那個位置存在、且內容真的是它說的那個東西。
     對不上的請寫「說是 X，實際是 Y」。

【硬性規則】
1. 每一條回報都必須附上原文引述，一字不改。引不出原文的不要寫。
2. 涉及數字的判斷請把算式寫出來。
3. 如果你提出兩個以上互相衝突的修改建議，必須自己先調和，只給我一個最終建議。
4. 你的報告會交給另一位審查者逐條覆驗。不確定的標「不確定」。
5. 用繁體中文。

【回報格式】
每一條：類別 / 位置 / 原文引述 / 問題是什麼 / 建議改成什麼（給出可直接替換的文字）。
最後給各類條數統計，以及一句話：「如果只能改三處，改哪三處」。
```

**「只能改三處」這一句值得留著。** 它會逼審查者自己排序，而不是丟一份沒有輕重的清單給你。

## 提示詞三・懷疑論者

這一份是最後才加的，也是投報率最高的一份。它回報了 41 條可查證的宣稱，其中 26 條在材料裡找不到依據——而前面六輪的讀者與編輯，**一條都沒有碰過**。

```
你是一位懷疑論的事實查核員。這份材料要對外發表，
你的工作是只查它對自己講的話是不是真的。

【你要查的材料】
<你的材料>

【背景】
<背景：作者是誰、材料裡引用的數據是從哪來的>

【你的範圍，請嚴格遵守】
要查的：材料裡每一個可以被檢驗的宣稱——所有數字、比例、時間、次數，
以及所有形如「一半」「大部分」「通常」「最常見」的量化或準量化說法。

對每一條，問三個問題：
1. 材料裡有沒有提供這個數字的來源或計算方式？沒有的話，讀者憑什麼相信？
2. 這個數字跟材料其他地方的數字對得起來嗎？請把算式寫出來。
3. 這是「作者身上發生過的事」還是「會發生在讀者身上的事」？
   材料裡有沒有把前者寫成後者？

不要查的：這份材料的核心命題。那是它的立論，不是查證題。
也不要評論寫作風格、排版、章節順序。

【額外一類】
倖存者偏誤：材料裡有沒有把「作者這一次成功的路徑」寫成
「照這樣做就會成功的方法」？有沒有哪裡該講而沒講失敗率、
前提條件、或這套做法不適用的情況？

【硬性規則】
1. 每一條都要附原文引述，一字不改。引不出原文的不要寫。
2. 每一條數字判斷都要把算式寫出來。
3. 你查不到的，寫「材料裡沒有提供依據」；你不確定的，寫「不確定」。
   不要用你自己的常識去補作者沒寫的數字。
4. 你的報告會交給另一位審查者逐條覆驗。
5. 用繁體中文。

【回報格式】
每一條：位置 / 原文引述 / 這是什麼宣稱 / 材料裡有沒有依據 /
算式（如適用）/ 建議改成什麼（要保留原意，只是把話說到證據撐得住的程度）。
最後給兩個統計：「有依據的宣稱幾條、沒依據的幾條」，
以及一句話：「這份材料最禁不起追問的一句話是哪一句？」
```

**最後那一句「最禁不起追問的一句話」，是這份提示詞裡最有價值的一行。** 它逼審查者做一次全域排序，而它指出的那一句，通常就是你自己心裡也有點虛的那一句。

## 提示詞四・通讀

分段審完之後才跑這一份。它不看單頁細節，只看跨章節。

```
你是一位通讀審查員。這份材料已經逐章審查過幾輪，章節內部的問題大致清乾淨了。
你的任務不是再審一次章節內細節，而是照順序讀完，
只回報「跨章節」才看得見的問題。

【你要讀的範圍，請依序讀】
<依序列出你的材料>

【背景】
<背景>

【只回報這四類】
P 類・讀者狀態弧線：某一處假設讀者「已經知道／已經會」的東西，
     前面真的教過嗎？在哪裡教的？請寫出「這裡用了 X，
     但 X 第一次出現是在 Y（或全篇沒教過）」。
     反過來也算：某個概念教完之後，後面該用卻沒用。
Q 類・承諾兌現鏈：任何「後面會講」「第某章有」，
     往後翻是否真的兌現、跟預告是否一致。
R 類・重複與空缺：同一件事講了三次以上，或兩章之間該有的銜接沒有。
S 類・語氣與難度曲線：難度有沒有突然跳升的地方？
     語氣有沒有某一段忽然變成寫給專業人士看的？

【不要回報】
- 單一段落內部的錯字、標點、表格——那些已經審過了
- 任何會移動編號的建議（新增、刪除、合併、拆分）

【硬性規則】
1. 每一條都要附原文引述，一字不改。引不出原文的不要寫。
2. 位置一律以材料自己的編號為準，不要拿檔案行號當頁碼。
3. 涉及數字的判斷請把算式寫出來。
4. 你的報告會交給另一位審查者逐條覆驗。不確定的標「不確定」。
5. 用繁體中文。

【回報格式】
每一條：類別 / 起訖位置 / 原文引述 / 問題是什麼 / 建議怎麼改。
最後給各類條數統計，以及一句話：
「一個新手照順序讀完，最可能在哪裡卡住？」
```

**第 2 條規則是被踩出來的。** 有一輪的審查者拿到的是原始檔，它把檔案的**行號**當成了頁碼回報，位置全錯。內容沒有捏造，但你照它給的位置去找會撲空。

## 收到報告之後：你要做的三件事

**一、每一條都回查原文。** 不要因為它引了原文就相信——要真的去看那一行是不是長那樣。七輪下來 0 筆捏造，但那是因為提示詞裡寫了「會交給另一位覆驗」；**告知會被查，不等於免查。**

**二、分成真、半真、不採納三堆，不採納的要寫理由。** 寫理由是給未來的自己看的——下一輪同樣的建議再出現時，你不用重想一次。

**三、能用程式查的，不要花 AI 的注意力。** AI 很會讀，但不會數。實測它把 58 數成 46、把行號當頁碼。編號有沒有缺、交叉引用指不指得到、用語統不統一——這些寫一支小腳本跑，結果可複驗，而且每改一次就能重跑一次比對差異。把 AI 的注意力留給它真正強的：讀懂意思。

## 這一套適用在哪裡

任何「沒有實跑可以當裁判」的東西——報告、企劃、合約、簡報、課程、說明書。第六部講的交叉審查靠實跑分勝負，程式跑一次就知道誰對；但大多數工作沒有這種奢侈品。

沒有客觀真值的時候，代替品是這兩件事：**讓不同角色各自看，而且每一條都要拿出原文。**
