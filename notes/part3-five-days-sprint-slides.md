# 五天衝刺：從零到可玩原型

<div class="lead">這是<b>五個階段</b>，不是五個日曆日——一次只守一個主戰場，做完才進下一個。</div>

| 五個階段 | 核心任務 | 造物者的把關重點 |
| :--- | :--- | :--- |
| **階段一** | 核心閉環 | 骰子、移動、薪資、破產判定跑得通 |
| **階段二** | 資料注入 | 擴充 20 張職業與基礎機會卡 |
| **階段三** | 機制深化 | 引入三級記帳制與財務分錄 |
| **階段四** | 體驗重構 | 介面拋光、排查通知與跑版 |
| **階段五** | 數值收斂 | 千局模擬測試、平衡性收口 |

- 節奏勝於速度，每一步都踏在可驗證的程式碼基線上
- 五個階段涵蓋 <b>第 1～20 批</b>、共 49 份變更說明，總共花了六個日曆日（8/25 深夜開工）
- <span class="highlight">實際交付是交錯進行的</span>，不是一天做完一階段——真實逐日流水帳見頁 74

# 階段二：資料驅動的威力

<div class="lead">卡片是卡片、規則是規則；加一張卡，絕不能動到算錢的那段程式。</div>

<div class="grid">
  <div class="box">
    <strong>傳統硬寫陷阱</strong><br>
    每張卡的效果都寫死在程式的判斷式裡<br>
    <i>加一張新卡就要重寫整個遊戲</i>
  </div>
  <div class="arrow">➔</div>
  <div class="box blue">
    <strong>資料驅動架構</strong><br>
    卡片只是一張獨立清單（JSON，一種電腦看得懂的表格寫法）<br>
    <i>「名稱、成本、月收益、技能需求」</i>
  </div>
  <div class="arrow">➔</div>
  <div class="box red">

    半小時內灌入 20 張在地職業<br>
    <i>算錢的核心程式一字未動</i>
  </div>
</div>

- 這正是為什麼不會寫程式的人，也能指揮 AI 輕鬆擴展遊戲內容

# 改造示範：每筆金錢變動都要留一筆帳

<div class="lead">會計分錄是底線，每一塊錢流向都必須說得出由來。</div>

| 玩家動作 | 傳統遊戲作法（容易對不上） | FinFlow 鐵律作法（會計日記帳） |
| :--- | :--- | :--- |
| **買進出租套房** | 現金直接扣 20 萬，結束 | 借：不動產資產 100 萬 / 貸：現金 20 萬、銀行借款 80 萬 |
| **每月發薪日** | 現金加 5 萬、扣 3 萬 | 借：現金 5 萬／貸：薪資收入 5 萬；借：生活支出 3 萬／貸：現金 3 萬 |
| **年終結算** | 現金只看剩餘總額 | 資產負債表與現金流量表即時連動配平 |

- 「借／貸」是會計的記法：**一筆錢從哪來、到哪去，各記一次**，兩邊加總必須相等
- 當帳目對不上時，這份流水帳就是最好的除錯對帳單

# 階段四：介面重整與細節打磨

<div class="lead">功能做完只是 60 分，畫面讓人一眼知道該看哪裡，才能稱為作品。</div>

<div class="grid">
  <div class="box">
    <strong>資訊超載盤面</strong><br>
    狀態、卡片、對話框擠成一團<br>
    <i>玩家找不到該按哪裡</i>
  </div>
  <div class="arrow">➔</div>
  <div class="box blue">
    <strong>三欄經典佈局</strong><br>
    左側個人面板・中間主遊戲盤<br>
    <i>右側永遠只留當前回合決策區</i>
  </div>
  <div class="arrow">➔</div>
  <div class="box red">
    <strong>乾淨視覺交付</strong><br>
    把背景雜訊轉移為彙總抽屜<br>
    <i>主視覺聚焦在關鍵數字</i>
  </div>
</div>

- 介面設計的重點不是畫圖好看，是「引導玩家做決策」

# 階段回顧：前四個階段建立的資產

<div class="lead">作者走完前四個階段時，手上已經不是空想，而是一個隨點隨玩的軟體。</div>
