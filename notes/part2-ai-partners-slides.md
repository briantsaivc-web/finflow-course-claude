# 那它們到底差在哪？

<div class="lead">差別不在「誰比較聰明」，在你已經在用什麼。</div>

| | 一句話定位 | 你可能已經在用它的原因 |
| :--- | :--- | :--- |
| **ChatGPT** | 最多人用、教學文章最好找 | 身邊的人都在用，卡住時問得到人 |
| **Gemini** | 跟 Google 的服務綁在一起 | 你的信箱、雲端硬碟、文件都在 Google |
| **Claude** | 擅長長文件與程式的來回修改 | 你要一直丟長規格書給它讀 |

- 這頁刻意**不寫價格、不寫額度、不寫誰比較強**——那些每隔幾個月就會變一次
- 真的想比，就三家都開來問同一個問題，看誰的回答你比較看得懂

# 免費版做得到什麼？

<div class="lead">這堂課從頭到尾要你做的事，免費版都能做。</div>

| 這堂課要你做的事 | 免費版 |
| :--- | :--- |
| 把想法講給 AI 聽，請它整理成規格書 | ✓ |
| 來回討論、修正方向 | ✓ |
| 請它寫出第一版程式 | ✓ |
| 用大白話描述**畫面出錯的狀況**（也就是 bug），請它找原因 | ✓ |
| 請它一次生成一批卡片內容 | ✓ |
| 邊聊邊看到成果（本部後面會介紹的那個側邊窗格） | 視方案而定 |

- 免費版真正的限制是**用量**：問太多次會請你等一下，不是「功能被鎖住」
- 唯一不保證的是最後一項：Claude 官方說明列出免費方案可用，另兩家沒寫清楚（見本部側邊窗格那一頁）
- 額度數字每家都在變，這裡不寫死；你自己用一天就知道夠不夠

# 案例：這本書的大綱，就是這樣長出來的

<div class="lead">我沒有先想清楚 134 頁要寫什麼。我只是講給 AI 聽，然後一輪一輪改。</div>

| 版本 | 頁數 | 這一輪加了什麼 |
| :--- | :--- | :--- |
| v1.0 | 102 | 當時只規劃五部：震撼彈／心法／工具／實作／讀者實作題 |
| v1.1 | 112 | 三大 AI 白話介紹、做完之後的進階方向 |
| v1.2 | 120 | 「有想法就跟 AI 講」實例、卡片一層層長大案例 |
| v1.3 | 130 | 新增「畫面與操作體驗一路怎麼改」專節，引用四個真實版本 |
| v1.4 | **134** | 過一輪待確認事項，把暫定的東西一個一個定案 |

- 第一版只有 102 頁而且很空。**它的價值不是完整，是讓我有東西可以改**
- 每一版加了什麼都留著紀錄——這就是<b>習慣 ③ 和 ④</b>長什麼樣子（定義在後面四頁，這裡先看樣子）
- 順帶一提：後來又長出第六、第七部，現在是**七部**。<span class="highlight">大綱本身也是一路長大的</span>
